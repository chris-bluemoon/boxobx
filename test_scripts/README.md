# Boxbox manual/standalone test scripts

These are plain Dart scripts (run with `dart run`, not `flutter test`) used
to validate individual pieces of the backend pipeline quickly, without
needing to launch the full app or a simulator. They hit real production
code in `lib/` directly, so a passing script is a genuine signal that
piece works -- these are not mocked.

For the real on-device/simulator black-box test (actual Push-to-Talk
button press, full pipeline, real audio), see
`../integration_test/ptt_flow_test.dart` instead.

## Scripts

### `gunther_voice_test.dart`
Exercises `GroqService` + `TtsStreamingService` directly: sends a sample
driver utterance to Groq, streams Gunther's response, synthesizes it via
Cartesia, saves the result to `gunther_output.wav`, and plays it with
`afplay` (macOS only). Useful for quickly tuning the system prompt or
testing a new voice ID without needing the app running at all.

Requires a real `.env` at the project root with `GROQ_API_KEY`,
`TTS_API_KEY`, `TTS_PROVIDER`, `TTS_VOICE_ID` populated. Hits live APIs
and uses real credits every run.

```bash
dart run test_scripts/gunther_voice_test.dart "We're losing the gap to P2!"
```

### `gt7_decode_test.dart`
Validates the GT7 UDP telemetry Salsa20 decryption + byte-offset parsing
logic in `lib/services/telemetry_udp_service.dart`, using a synthetic
packet (no real PS5 required). Builds a fake plaintext packet with known
field values, round-trips it through the real encrypt/decrypt transform,
and asserts every field comes back correctly. Pure logic test, no network
calls, no API keys needed.

```bash
dart run test_scripts/gt7_decode_test.dart
```

### `tracks_db_load_test.dart`
Structural sanity check for `assets/config/tracks_db.json` (generated by
`../tools/generate_tracks_db.py`): confirms the file is valid JSON, every
track has a positive length, and every sector bounding box is
non-degenerate (min < max on both axes). No API keys needed.

```bash
dart run test_scripts/tracks_db_load_test.dart
```

## Generated artifacts

`gunther_output.wav` is overwritten each time `gunther_voice_test.dart`
runs and is gitignored -- don't rely on its contents persisting between
runs.
